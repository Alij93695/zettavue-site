Zettavue

Privacy Policy

Last updated: 12 October 2026

Zettavue is the private publishing tool of the ZettaVue Kids YouTube channel. It is used only by the channel's owner, on the owner's own computer, to manage that channel. This policy explains what Google user data it uses and why.

Google user data the app accesses

When the channel owner signs in with Google, Zettavue asks for these permissions on the owner's YouTube account:

  • Upload videos (youtube.upload), to upload the owner's own song videos.
  • Manage the YouTube account (youtube), to set each video's title, description, thumbnail, schedule and "made for kids" setting, and to read the channel's own video list.
  • View the YouTube account and its analytics (youtube.readonly, yt-analytics.readonly), to read the channel's own view counts and watch time.

How the data is used

The data is used only to publish and schedule the owner's own videos on the owner's own channel, and to decide what to post next. Zettavue does not use Google user data for advertising, does not sell it, and does not transfer it to anyone else. It does not use the data to train AI or machine-learning models.

Where the data is kept

The sign-in token and the channel's publishing records are stored only on the owner's own computer. Zettavue has no server and no database of its own, and it does not collect data from viewers of the channel.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also removes the app's stored access.

Google API Services User Data Policy

Zettavue's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Zettavue uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Children

ZettaVue Kids makes videos for children, but Zettavue (this tool) is used only by the adult channel owner. It collects no information from children or from any viewer.
